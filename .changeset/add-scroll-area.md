Add `ScrollArea` — a custom-styled scrollbar for a fixed-size panel (a side nav, a long dropdown, a code pane), built on `@radix-ui/react-scroll-area`. Keeps real native scrolling (wheel, touch, keyboard, momentum) and only re-skins the visual thumb/track; the scrollable viewport is keyboard-focusable so arrow-key scrolling works without a mouse.
